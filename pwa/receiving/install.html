Set up this phone for receiving

About two minutes, once per phone. If you reached this page without a warning, step 1 is already done.

iPhone

  1. Trust the certificate. Follow step 1 on the setup card. After installing it, go to Settings → General → About → Certificate Trust Settings and switch it on. Without that last switch, the phone installs the certificate but still refuses it.
  2. Add to Home Screen. In Safari, tap the Share button, then “Add to Home Screen”. iPhones never offer this on their own — it is always the Share menu, and it has to be Safari.
  3. Open it from the new icon and finish the phone check.

Android

  1. Trust the certificate. Follow step 1 on the setup card: open the certificate file, and when asked, install it as a “CA certificate”.
  2. Install the app. Use the button below, or the browser menu (⋮) → “Install app” / “Add to Home screen”.
  3. Open it from the new icon and finish the phone check.
