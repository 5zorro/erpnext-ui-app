Table Column Sizing — Industry Standard: table-layout: fixed + semantic column roles

Fixed columns have explicit px widths. Percentage columns shrink/grow proportionally with the container. The description/fill column has no width set — in fixed layout it absorbs whatever space remains after all other columns are satisfied. The container uses overflow-x: auto so a min-width on the table prevents columns from collapsing below readable thresholds. Numeric columns use font-variant-numeric: tabular-nums and right-align.
